# Why NewTemp preserves knowledge

NewTemp accepts both paths and text through Windows command-line quoting. Small changes to parsing or name allocation can change where user data goes. Preserve the input contract and tested quoting examples so later changes do not rediscover these decisions.

Docs contains reusable behavior and verification methods. Walkthrough contains concise dated context and experiences; Git contains code history. Keep each fact in its appropriate source and link to it.
