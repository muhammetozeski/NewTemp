# Unique names and complete errors

NewTemp v1.2.0 creates fresh directories for repeated requested names. It uses the original name first, then appends the first available Base36 suffix directly, without inserting a separator or changing characters already in the name. Runtime checks produced konu-test, konu-testa, and konu-testc when konu-testb was occupied by a file; the original directory was preserved and the new directory was empty.

The console now prints the complete exception ToString() with the requested English prefix for initialization and operation failures. A real destination failure included System.IO.IOException and the operation's stack trace. No failure message claims whether a directory or partial file exists. Both executables were rebuilt and signed, and the installed executable was updated. Build outputs remain in bin and obj, final variants in publish, and disposable check files outside the project in the existing NewTemp folder. General memory was not edited; the existing local Logger retention change was preserved.

See [the input and allocation contract](../Docs/Input-and-Allocation.md) for the current behavior.
