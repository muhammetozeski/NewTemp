# NewTemp first delivery context

NewTemp is a .NET 10 / C# 14 Windows console utility for short disposable sandbox paths. It allocates the first free name using the supplied letters-first Base36 alphabet, moves existing items, stores quoted-filename content verbatim, and treats invalid directory names as text. Configuration lives beside the executable with root, limit, and language fallbacks.

A real raw-argument test showed that Environment.CommandLine reconstructed the text and lost repeated spaces and quotes. GetCommandLineW preserved them; keep the single decoded argument and raw multi-argument paths distinct. The self-contained executable passed 100 integration assertions across 18 scenarios, and the settings probe passed 26 assertions without creating the default root. The framework-dependent executable also preserved named content.

Both Windows x64 publish outputs have valid digital signatures. The self-contained executable and sample settings are installed under C:\E\kp\aaBenimProgramlarim\NewTemp, with a shortcut.
